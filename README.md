# Sayali Sutar Portfolio

A responsive, accessible, static portfolio built with HTML, CSS, and vanilla JavaScript. It has no framework or external runtime dependencies.

## Included
- Professional profile photo optimized as WebP
- Responsive layout and mobile navigation
- Light/dark theme toggle (preference is remembered when browser storage is available)
- Project filters and expandable case studies
- Active section navigation, back-to-top control, and copy-email feedback
- Reduced-motion support, visible keyboard focus, and semantic HTML
- CV PDF in `assets/Sayali_Balasaheb_Sutar_CV.pdf`

## Publish with GitHub Pages
1. Create a repository named `dev-sayali.github.io` in the `dev-sayali` GitHub account.
2. Upload the contents of this folder (not the enclosing ZIP) so `index.html` is at the repository root and the `assets` directory is alongside it.
3. In the repository, open **Settings → Pages**. Set the source to **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for the Pages deployment to complete, then visit `https://dev-sayali.github.io/`.

Project links open the public project websites; they do not imply that this portfolio contains source code for those projects. Review the descriptions before publishing to ensure all contribution details remain accurate and appropriate to share.
