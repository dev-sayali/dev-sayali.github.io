# Sayali Sutar Portfolio

A responsive, accessible, static portfolio built with HTML, CSS, and vanilla JavaScript. It has no framework or external runtime dependencies.

## Included
- Professional profile photo optimized as WebP
- Responsive layout and mobile navigation
- Light/dark theme toggle (preference is remembered when browser storage is available)
- Project filters and expandable case studies
- Active section navigation, back-to-top control, and copy-email feedback
- Reduced-motion support, visible keyboard focus, and semantic HTML
- CV PDF in `assets/Sayali_Balasaheb_Sutar_CV.pdf`
